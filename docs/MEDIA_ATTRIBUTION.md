## README demo recording

The [demo recording](https://github.com/user-attachments/assets/dc29eef2-4006-4929-9297-0d0702a7ea53) uses the same FOSDEM talk under the license above.

The recording uses the excerpt **00:02:46.520–00:12:46.520** (600 seconds). The source was trimmed,
resized and transcoded; the WebUI was recorded while the browser played that excerpt at normal speed
and the connected board generated the transcript live. The original visible speaker and FOSDEM credits
are retained. A persistent attribution strip is added below the recorded interface. The original source audio
is synchronized with the screen capture; recognition text and metrics are actual UI output. Capture timestamps were corrected against the
player playback clock to keep the original normal-speed soundtrack synchronized.
