# Model and SDK resources

Audio8-ASR-Infinite-80ms and Audio8-ASR-Infinite-160ms have independent model
packages and share the [Demo and SDK](../README.md). Keep the variants in
separate roots. Use [model setup](MODEL_SETUP.md) for downloads and
[package layout](MODEL_PACKAGE.md) for the current models.json/AIDEM contract.

For application integration, see [SDK installation](../sdk/README.md),
[Python API](../sdk/PYTHON_API.md), [C ABI](C_ABI.md) and [examples](../examples/README.md).
Use matching Python package, C headers and native library from the same SDK delivery.
